## 🌌 Overview

This portfolio is built to reflect the intersection of **Data Analytics, Machine Learning, and Modern Web Engineering**. Rather than a static template, it offers an immersive, interactive data universe featuring:

- **Cinematic 3D Neural Network**: Real-time particle physics, depth-of-field perspective, dynamic lighting, and pointer parallax powered by Three.js and React Three Fiber.
- **Interactive Data Lab**: Live analytics dashboard with filtering by region and product category, dynamic KPIs, and 4 interactive visualizations (Revenue Area Chart, Category Donut, Profit Trends, Regional Comparison).
- **Interactive Tech Constellation**: Connected capability map with dynamic relationship tracing (e.g. *Python → Data Processing → Machine Learning → Predictive Insights*).
- **Featured Machine Learning Applications**: Direct live demos and architectural case studies for four full-stack AI and analytics applications.
- **⌘K Command Palette**: Fast keyboard navigation allowing direct jumps to sections and external links.
- **Editorial Dark-Tech Aesthetic**: Custom design system crafted with electric cyan, royal violet, glassmorphism, and monospace typography.

## ⚡ Performance & Engineering Highlights

- **Bundle Optimization**: Custom Vite manual chunking isolates heavy libraries (`Three.js`, `Recharts`, `Framer Motion`) into separate on-demand bundles for fast sub-second First Contentful Paint.
- **GPU Resource Management**: Single `useFrame` requestAnimationFrame loop in Three.js with memoized buffer geometries and cleanup on unmount.
- **Accessibility & Motion Safety**: Respects `prefers-reduced-motion` to smoothly disable WebGL physics and complex animations for sensitive users.
- **Type Safety**: 100% strict TypeScript (`tsc --noEmit`) with zero compilation warnings.

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v18 or higher) installed on your machine.

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/nishhh2004/portfolio.git
   cd portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the local development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:5174](http://localhost:5174) in your browser.

4. **Build for production**:
   ```bash
   npm run build
   ```
   Generates optimized assets inside the `dist/` folder.

5. **Preview production build locally**:
   ```bash
   npm run preview
   ```
